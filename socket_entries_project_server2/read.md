这里的解释是run.py文件：
    - threading.Thread(target=run) ：创建一个线程，线程要执行的任务是 run 函数。
    - t.start() ：启动线程，线程开始执行 run 函数的内容。
    - threads.append(t) ：把线程对象保存到列表，方便后续管理。
    - t.join() ：主线程会等待 t 这个线程执行完毕后再继续。这样可以保证所有线程都执行完毕后，主程序才结束。

    你这段代码的效果
    - 一共会创建100个线程，每个线程都会执行一次 run() 函数。
    - 这些线程是 并发 启动的，也就是说它们几乎是同时开始执行的（具体是否真正并行取决于CPU核心数和Python的GIL机制）。
    - 主线程会等待所有子线程都执行完毕后再退出。

Thread装饰器文件的解释：
#由于 thread.join() ，主线程会等待 run 线程执行完才继续，所以 和直接调用run()几乎没区别 （只是多了一个线程切换）。
    - 这个装饰器的本意是让 run 函数在新线程中执行，并且控制最大线程数。
    - 但由于你在 inner 里 thread.start() 后立刻 thread.join() ，所以每次只会有一个线程在跑，和直接调用 run() 区别不大。
    - 如果你去掉 thread.join() ，那就会变成真正的多线程异步执行（但要注意线程安全和主线程退出问题）。
